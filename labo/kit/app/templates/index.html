Ce que vous allez observer

  1. La redirection vers Keycloak (étape 1 du flux par code d'autorisation), avec code_challenge (PKCE), state et nonce dans l'URL.
  2. Le retour avec un code à usage unique, échangé côté serveur contre les jetons.
  3. Le jeton d'identité (qui, émis par qui, pour quelle application, jusqu'à quand, comment authentifié) et le jeton d'accès (pour appeler une API).
  4. Une page réservée à un rôle : l'autorisation se décide dans l'application, pas chez l'IdP.
